# Atmospheric-AI-Assignment
Take home assignment 

The write-up (PDF) is the main document: it sets out my assumptions, approach,
example output, and answers to all three questions. `Question 1.py` implements
the Question 1 approach for the steam crackers sourcing model.

## Running the script

Requires Python 3 with pandas and numpy.

Place the seven CSV files from the take-home assignment in the same folder as the script:

- `facilities.csv`
- `facility_ownership.csv`
- `feedstock_bids.csv`
- `organizations.csv`
- `port_throughput.csv`
- `transport_legs.csv`
- `units.csv`
